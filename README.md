# Subtitle Finder

A Chrome browser extension that detects video playback on webpages, identifies movies and TV shows using accessible metadata, and helps users discover matching subtitles.

## Current Features

- HTML5 video detection
- Playback event monitoring
- Dynamic video element detection
- Webpage metadata extraction
- Video URL and filename analysis
- Title evidence ranking
- Identification confidence evaluation

## Planned Features

- TMDB metadata integration
- Subtitle discovery through an authorised subtitle API
- Subtitle matching and ranking
- User-controlled subtitle downloads

## Technology Stack

- JavaScript
- HTML
- CSS
- Chrome Extensions Manifest V3

## Project Status

Currently under development.
